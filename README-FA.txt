نسخه ارتقایافته سایت MAZIAR

ویژگی‌های اضافه‌شده:
- نشانگر حلقه‌ای طلایی و هاله نور دنبال‌کننده موس (فقط دسکتاپ)
- ساعت زنده با منطقه زمانی رسمی ایران (Asia/Tehran)
- ذرات طلایی سبک در پس‌زمینه
- ورود سینمایی کوتاه با نشان MAZIAR
- بخش امضای اختصاصی در انتهای صفحه
- دکمه شناور بازگشت به بالا
- بهینه‌سازی فاصله‌ها، اندازه‌ها، منو و کارت‌ها برای موبایل
- رعایت تنظیمات کاهش حرکت سیستم و غیرفعال‌شدن افکت‌های موس در موبایل

موسیقی یا پخش‌کننده موسیقی اضافه نشده است.

راه‌اندازی:
1) پوشه پروژه را باز کنید.
2) در ترمینال اجرا کنید: npm install
3) سپس اجرا کنید: npm run dev
4) برای نسخه نهایی: npm run build

نکته تصویر:
کد فعلی مثل نسخه قبلی تصویر را از مسیر /maziar-portrait.jpg می‌خواند.
اگر تصویر پرتره در پروژه اصلی‌ات وجود دارد، آن را در پوشه public با همین نام نگه دار:
public/maziar-portrait.jpg

اطلاعات تماس داخل سایت هنوز همان مقادیر نمونه قبلی هستند (your-email@example.com و your_username و شماره نمونه) و باید با اطلاعات واقعی خودت جایگزین شوند.
